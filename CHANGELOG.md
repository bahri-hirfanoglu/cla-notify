# Changelog

## 0.1.0

Initial release.

- Desktop notification when Claude asks a question, waits for approval or input, or finishes
  a turn, on macOS, Linux and Windows.
- Clicking a notification returns focus to the terminal the session runs in.
- `/cla-notify:config`, `/cla-notify:test` and `/cla-notify:doctor` slash commands.
- Configurable text, sound, duration, corner, theme and per-event on/off via
  `cla-notify config`.
